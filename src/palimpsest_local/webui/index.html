개요

이 호스트의 실제 리소스와 최근 관찰을 확인합니다.

마지막 전체 갱신 성공아직 없음
호스트 관찰은 Hub 없이 동작합니다. 원격 검색·다운로드·업로드는 레이어·이미지에서 명시적으로 요청합니다. 콘솔·변경 작업은 palimpsest web --allow-control의 새 CLI 링크로 허용하세요.

로컬 리소스를 불러오는 중입니다.

새 VM 실행

로컬 이미지(클라우드 이미지 또는 OCI 아카이브)나 레지스트리 참조로 가상 머신을 실행합니다.

독립 데이터 볼륨

이름 있는 볼륨은 VM 제거와 별개로 보존됩니다. 연결할 볼륨의 백엔드를 먼저 선택하세요. 연결 가능 여부는 서버가 다시 확인합니다.

OCI 루트 보존 기본값: retain · VM 제거 시 루트와 순서 있는 레이어 연결 토폴로지를 함께 보존합니다.

최근 VM 실행 비동기 작업

이름 있는 데이터 볼륨 생성

한 번 생성한 독립 데이터 디스크를 VM에 연결해 재사용합니다. VM 제거 시에도 데이터는 보존되며, 미연결 상태에서 정확한 이름 확인 후에만 별도로 삭제합니다.

클라우드 이미지 가져오기

원격 이미지 · 레이어

Palimpsest Hub는 아래에서 이 탭에 연결하거나 서버 환경의 인증을 사용합니다. Docker Hub는 별도 연결입니다. OCI 이미지와 부팅용 클라우드 VM 이미지는 서로 다른 런타임입니다.

토큰은 이 탭의 메모리에만 보관하며 연결 해제 시 지웁니다. 탭 연결 없음 · 서버 설정 사용

연결을 선택하고 조회하세요. 원격 목록은 자동 갱신하지 않습니다.

로컬 빌드 · 아티팩트를 Palimpsest Hub에 업로드

로컬 출력의 다이제스트와 그래프를 다시 검증합니다. OCI 빌드는 프로젝트 키 기반 native Hub, 클라우드 이미지·SquashFS는 원래 Keystone 토큰 기반 Hub를 사용합니다.

최근 다운로드 · 업로드

새 이미지 빌드

호스트 컨텍스트 디렉터리에서 BuildKit으로 이미지를 빌드합니다. 로컬 캐시를 사용하며 Hub 로그인이 필요 없습니다.

최근 이미지 빌드 비동기 작업

스토리지 보고서를 불러오는 중입니다.

Lima VM 디스크는 Lima의 상태 디렉터리 (~/.lima)에 있습니다. Palimpsest 스토리지 이동에 포함되지 않습니다.

상태 루트 이동

파일을 새 위치로 옮기고 상태 루트를 변경합니다.

기존 상태 루트 지정

파일 이동 없이 사용할 상태 디렉터리를 변경합니다.
