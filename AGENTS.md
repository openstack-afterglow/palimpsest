# Palimpsest contributor entrypoint

Before work read README Development, the latest [handoff](docs/development-handoff.md), [ARCHITECTURE.md](ARCHITECTURE.md), [contributor workflow](openspec/specs/contributor-workflow/spec.md), and [CI safety/performance](openspec/specs/ci-safety-and-performance/spec.md). [`agent.md`](agent.md) is a resume pointer, not another approval source. Compare actual branch/HEAD, staged/unstaged changes, recent commits, source and dated evidence; preserve other work. Astra plans/manages, Sol develops with independent review; report unavailable roles rather than silently replacing them.

Approval is scoped to an exact ref, action and resource. A documentation/continuation request or reviewer signoff does not authorize publication, merge, private helper transfer/execution, remote installation, native/cloud proofs, GPU reassignment, driver reset or VM deletion. Do not route around a blocked action. Read-only PCI/IOMMU/driver inspection and portable/CPU-only results do not prove passthrough or CUDA. Recheck current baseline and ownership before separately authorized operations.

For source changes, update affected architecture/contracts and docs after source review; stamp only reviewed source and run the applicable working/staged guard. Start verification at the changed node/lane; run native/ML/GPU proofs only with their prerequisites and authorization. Distinguish test-defined, test-passed and live-verified; record actual SHA, checks, failures and pending approvals in the handoff without exposing secrets.

CI changes must retain hosted-only PR execution, gated trusted-ref native jobs, offline runner21, least privilege, repo-wide serialization, quota/cleanup bounds and fail-closed verdicts. Measure before/after; preserve publication exceptions and shard gaps until owner decisions. No commit, push, deploy, helper transfer or device mutation without specific approval.
