Images & layers

Verified downloads are streamed in chunks. Project managers can delete project-owned registrations without dependent layers or foreign-project grants; shared catalogs remain system-managed and blob cleanup is deferred.

REGISTER

Upload an artifact

Whole-file SHA-256 is calculated before transfer and validated again by the server. Registration metadata is locked for each session. Resume with the same file or abort before replacing it.

Project members and above can upload project-private artifacts. Readers can query and download visible content only. Shared catalog publication remains system-managed.

SERVER BUILD

Build a layer

Requires current project member authority and a configured isolated host worker; readers can view project build status. No recipe runs in the API process.

Build a playbook

Git builds need an allowed HTTPS repository and a full 40-character commit. Successful jobs publish an image under the chosen name and audience, subject to quota. Builds target linux/amd64. No credentials belong in URLs or Dockerfiles.

Playbooks
